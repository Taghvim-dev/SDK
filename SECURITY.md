# Security

Do not file a public issue containing an API credential, personal information, customer data, exploitable details or production logs. Request a confidential reporting channel using the contact page at https://taghvim.dev/#contact, labelled "Confidential security report". Do not send secrets in the initial message.

Client libraries must never log authentication tokens, expose live keys to browser assets, or follow unapproved HTTP endpoints. Only isolated, approved test credentials may be used for integration checks.
