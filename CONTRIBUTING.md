# Contribution policy

Original contributions are submitted under Apache-2.0 unless explicitly agreed otherwise in writing. Contributors must have rights to their submissions and preserve applicable third-party notices. Propose changes with a test demonstrating behaviour, evidence of canonical operation compatibility, and a release-impact description.

Do not add administrative endpoints, payment callbacks, real account credentials or private implementation details to this public SDK. Changes to the API contract, SDKs and cookbooks must be synchronized before a release.
